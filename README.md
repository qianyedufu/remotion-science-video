# remotion-science-video

用 Remotion 制作配合自选音乐的中文科普视频的 Codex 技能，覆盖资料核查、音乐卡点、图表动画、代码音效、10秒试片、成片检查和小红书发布素材。

这是提供给编程智能体的制作指南，需要智能体执行相应操作；仓库本身不包含视频生成程序、Remotion 插件源码、音乐或成片。

## 默认制作方式

- 1920×1080、30fps、16:9横屏，不配音，以中文标题、字幕和图表讲解。
- 分析真实音乐的节拍、重音和乐句，以统一时间线安排切场和动画。
- 背景音乐从起点连续播放，关键动作叠加低音量的代码合成音效。
- 新项目先制作约10秒试片，确认风格后分段完善；已有确认和整片授权继续有效。
- 检查实际导出的画面、音轨连续性、数据与覆盖范围。
- 按需生成小红书横竖封面、标题、正文和标签；不自动发布。

用户明确提供的规格和偏好优先于默认值。

## 安装

### 方式一：让 Codex 安装

在支持 skill-installer 的 Codex 环境中输入：

```text
请安装 https://github.com/qianyedufu/remotion-science-video/tree/main/skills/remotion-science-video 中的技能。
```

### 方式二：手动复制

下载或克隆本仓库，把 `skills/remotion-science-video` 整个文件夹复制到 Codex 的个人技能目录：优先使用 `$CODEX_HOME/skills`，未设置时通常为 `~/.codex/skills`。

保留 `SKILL.md`、`agents/` 和 `references/` 的相对结构。重新打开会话或等待环境刷新后，确认技能列表出现 `remotion-science-video`。

## 使用示例

```text
使用 $remotion-science-video 制作知识科普视频。
主题：太阳能电池如何发电
内容范围：光照、载流子产生、电荷分离与外电路
音乐：我提供的音频附件
视觉偏好：简洁图解，深色背景，重点用暖色标注
先做开头10秒预览，确认后继续。
```

继续修改已有工程时，附上工程位置与修改要求。仅需要封面和文案时，提供最终成片或已核实的内容资料即可。

## 环境与依赖

- 能读取技能并操作本地文件的 Codex 或兼容智能体环境。
- 实际视频制作需要 Node.js、Remotion 工程及其运行依赖。新建工程时按所用 Remotion 版本配置。
- 推荐配合 Remotion 插件中的创建、动画、预览与渲染指南；没有插件时可参考项目安装版本的官方文档。
- 节拍分析、音频处理和成片检查需要环境中可用的音频分析、媒体处理与预览工具。技能不捆绑或自动安装这些工具。
- 时效性事实需要访问可靠来源；音乐、字体、图片和其他素材由使用者自行提供并确认使用权。

本技能与插件自带的 `remotion-create` 不同：后者提供通用视频工程创建入口，本技能规定配乐科普视频的制作流程，两者可配合使用。
