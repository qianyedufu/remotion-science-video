# 音乐、卡点与动画校验

## 建立一条共同时间线

1. 确认用户源音频与工程副本一致，记录路径、时长、采样率，必要时记录文件哈希。
2. 解码并提取节拍及瞬态。稳定拍号可从BPM建立网格，再用实际瞬态修正；低频鼓击和宽频起音相结合，避免把镲片或旋律峰值全部当重拍。
3. 将算法估计的拍位、鼓击强度与置信度记录下来，分析乐句与起落段。能试听时复核开头、切场及收尾；不能试听时注明分析方式和未覆盖项。
4. 在场景时间表中引用音乐事件，禁止各组件各算一套时间。帧号取 `round(秒数 × fps)`，落点与目标事件的量化误差通常不超过半帧。
5. 使用连续背景音乐层覆盖全片。视觉分段不影响音乐播放位置。代码音效用独立事件叠加，避免重复渲染时叠加多次。

建议记录两个文件，可按工程既有格式调整：

```text
docs/music-beats.csv
event_id,source_seconds,frame,strength,kind,confidence

docs/timeline.csv
scene_id,start_frame,duration_frames,entry_event_id,animation_events,main_message
```

节拍表必须来自实际音乐，示例字段不代表已分析完成。30fps下1帧约33毫秒，分析记录与导出片需用相同的零点和偏移。

## 连续播放与自然收尾

- 默认源曲从0秒连续播放，在精简后的视频终点附近选择合适乐句结束；开头有音乐留白时，可用标题入场配合，避免随意截掉起奏。
- 对齐章节不依赖音乐剪接；先调整画面时长，再微调节点。不要在“六小”或沿革入场处重复音乐、跳到另一乐段或重启同一音频。
- 末尾渐弱是收束手段，不能替代乐句选择。长度随素材决定，约1—2秒可作为起点，最终避免突断、长时间黑屏或无内容尾奏。
- 音乐不够长时先精简画面，或说明素材长度不足并请用户选择新音乐/允许循环；不擅自循环。用户要求整首时按整首排片。
- 若MP3解码导致固定延迟，可将原曲完整解码为PCM WAV后统一使用；保持采样顺序，不以删采样、改速度或拼中段“修复”节奏。

## 紧凑但保留动画

- 分开记录“入场”“展开”“完成后静止”三段时间。缩片先减少第三段，必要时按拍调整前两段，不把它们压成闪现。
- 多行条形按独立时刻浮现，标签、数值与条形协同。原始四步严格模式使用重拍；用户要求紧凑逐项动画时可按普通拍或半拍错开，始终服从其最新的节拍要求。检查中间帧，避免前几家实际上同帧出现。
- 沿革以年份和关键事件为中心，每家通常2—3个节点，以一至数个乐句呈现。音乐速度不同，不固定照搬某次作品约4秒的公司时长。
- 切入首家沿革可选择下一明确强鼓击，过门词与图标逐次出现填满该段，避免额外空等。
- 图表配色要跟对象/板块含义一致。过于相近的颜色使用标签补充；不用缺字字符充当图标。

## 同一幕中文字浮现

- 同一幕内的标题、副标题、正文、图表标签与关键数字应形成连续阅读顺序。优先按短句、行或完整信息组错峰浮现；数字与单位、标签与对应数值作为一个语义单元，不拆散到难以理解。
- 同层级文字采用一致的入场方向、位移幅度与缓动曲线，优先小幅滑入配合透明度渐变，接近落位时平稳减速。默认避免逐字弹跳、随机方向、明显回弹以及透明度或位置突然跳变；用户明确要求特殊风格时再调整。
- 相邻信息组的入场适度重叠：前一组接近落位时，下一组开始浮现，形成自然接续；不要让每行都经历“完全停止—空等—下一行突然出现”。错峰间隔与过渡时长按音乐、字数和阅读负担共同调整，不强求固定帧数，也不为连贯而让所有内容同时涌入。
- 使用同一场景的帧时间线连续计算透明度与位移，分段边界的状态应衔接。保持文本容器尺寸、行距和最终位置稳定；动态内容出现不应挤动已显示的文字，不因重新挂载组件而重播已完成的入场。
- 关键入场的起点仍服从当前项目的重拍、普通拍或半拍模式，缓动在拍位之间持续完成。严格重拍模式下，通过延长过渡或组织语义分组改善衔接，不擅自把起点挪到非重拍；保留必要阅读停留，不以卡点为由硬切文字或快速闪过。
- 连续播放试片与实际成片中的多组文字入场，检查是否有顿挫、闪烁、突跳、重播、布局抖动或节奏空档；再抽查首帧、过渡中间帧、相邻单元交接帧及稳定帧。不能仅凭单张截图判断动画丝滑；发现问题先调整错峰间隔、缓动与分组，再压缩静止等待。

## 验证实际成片

| 检查 | 证据与判断 |
| --- | --- |
| 参数与解码 | 检查1920×1080、30fps或用户指定值、预期帧数、音视频时长，并完整解码确认无错误 |
| 卡点 | 对照事件表检查切场和关键入场帧，抽查原曲强鼓瞬态与动画起点；不宣称每个音符均为强拍 |
| 图表过程 | 抽看首次出现、逐行中间、最终完成和切场前，确认数据、文字、颜色和边框正确 |
| 文字连贯 | 连续播放同一幕的多组文字入场，结合交接帧确认缓动、错峰衔接与阅读停留自然，没有硬切、闪烁、跳位或重复入场 |
| 沿革覆盖 | 核对对象数、节点数、每家公司最后一个节点是否在切场前完成 |
| 源曲连续 | 从导出MP4抽音轨，对照源音频多个时间窗口，特别是章节交界、疑似重复段和片尾前 |
| 起止听感 | 能试听则实际试听开头、章节交界和结尾；不能试听如实说明，用波形、响度和对齐结果提供有限证据 |

带音效及压缩编码的导出音轨不能要求逐字节等于源曲。可用多窗口互相关或匹配判断源曲对应位置：扣除已知固定偏移后应随视频时间连续推进；出现突然偏移才提示跳切或重播。渐弱区相关度降低需结合包络判断。

音效应有可控增益，混合后检查峰值、削波与结尾响度。缩短画面后要同步更新所有音轨、总帧数和导出配置。

最终检查通过再替代旧成片。用户要求清理输出时，确认绝对路径和文件清单，仅清理已被替代且用户授权范围内的文件。
