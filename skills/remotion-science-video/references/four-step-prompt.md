# 原始四步提示词与启动模板

## 用户提供图片中的四步原文

### 01 定规格

帮我做一部知识科普视频，主题：换成你的主题。用 Remotion 来做，1920×1080，30帧，16:9横屏；不配音，用中文字幕把知识点讲清楚；配乐用文件夹里这首音乐。

### 02 卡点

先分析这首音乐，测出每分钟多少拍，把每个重拍在第几秒列出来；画面每变一次，都落在重拍上。

### 03 配音效

每个关键动作都配一个音，用代码合成；音色用契合画面重点的乐器。

### 04 试片

先做开头10秒给我看；我确认后再一段一段往下做，哪段不好就重做那一段。

## 可直接复制的启动模板

把方括号内替换成实际输入；已经提供的文件或偏好直接复用。

```text
使用 $remotion-science-video 制作知识科普视频。

主题：[本次主题]
内容范围：[介绍哪些对象，先讲什么、后讲什么]
音乐：[上传的音频附件或本地完整路径]
已有工程：[有则填写；没有则新建]
视觉偏好：[已有认可风格则沿用；否则由你提出两个方向并推荐一个]

选题规划：主题确定后，按技能正文的“主题内容规划”，从运行原理、中国国内现状、关键技术与设备、设备关键供应商、相关市场变化和相关企业市值变化考虑内容。先列提纲与资料来源，再按受众和时长安排重点；不适用或数据缺失的方面明确说明。动态数据标注时间和口径，供应商关系核查到具体产品，市场与市值分开表述。

1. 定规格：用 Remotion，1920×1080、30fps、16:9横屏，不配音；用中文标题、字幕、图表讲清知识点。事实先核查，画面文字精炼。
2. 卡点：分析这首实际音乐的BPM、重音鼓点和乐句，列秒数与帧号。切场和关键动画落在重音上，音乐从开头连续播放，在合适乐句末收尾。
3. 配音效：关键动作使用代码合成短音效，音色贴合主题，音量不盖过原曲。
4. 试片：先做开头10秒预览，确认后分段推进；已确认的部分不重复询问，不满意的段落单独修订。

后续优化：图表有语义配色，数据逐项浮现；减少静止等待，保留动画过程；多对象的沿革各用一段短动画，按音乐合理分配时间。整片确认后导出MP4，并提供可编辑工程。
发布素材：制作小红书竖版与横版封面、推荐和备选标题、介绍正文与相关标签，不自动上传发布。
```

## 本次能源主题的结构示例

主题：中国能源央企“五大六小”。顺序：现有规模 → 电源板块结构 → 代表上市平台市值 → 各家发展史 → 收束。具体对象名单与统计口径每次核实。

已认可视觉可作为起点：深蓝黑底、青绿色线条、橙金色重点、清晰的中文无衬线文字，以及电厂、风机、光伏等简洁图形；换主题时按内容调整。

- 五大：国家能源、中国华能、中国华电、中国大唐、国家电投。
- 六小：三峡、国投、华润、中广核、中核、中国节能；按用户采用的行业称谓核实集团与电力平台关系。
- 规模对比覆盖全部对象，不再用国家能源的单家大数字代替总览。
- 装机结构展示火电、水电、核电、风电、光伏等构成，缺失部分和统计范围如实说明。
- 市值条形有颜色，标签写对应上市主体；不把某家上市公司的市值称为母集团市值。
- 各家沿革一段动效；“诞生—重组—转型”过门分阶段浮现，可加工程、整合连线、风机和光伏图标。
- 总览、占比和市值页减少完成后的静止时间；发展史按相近乐句长度压缩，保证所有对象完成展示。
- 若扩展到高校就业，集团就业不等于发电板块就业；报告中未单列某单位不代表0人。

以上是叙事示例，不能把某次成片长度、行情数字、就业人数、音乐文件路径或调色硬编码为通用事实。
